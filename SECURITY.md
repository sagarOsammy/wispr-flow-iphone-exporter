# Security policy

## Reporting a vulnerability

Please report a security issue privately through GitHub's private vulnerability
reporting feature. Do not include real transcripts, backup folders, audio, or
credentials in a public issue.

## Data handling

This tool processes private speech and may process sensitive identifiers from
an iPhone backup. It reads local files only, does not make network requests,
and does not transmit extracted data. Review the output before moving or
sharing it.

The public repository intentionally contains synthetic tests only. Real
backups, app containers, databases, audio, transcripts, and generated output
must remain outside version control.
